# 温度・気温・気圧を測定し表示するプロダクトを作成する

## 使用するハードウェア
- [M5Stack basic 2.6](https://docs.m5stack.com/ja/core/BASIC%20v2.6)
- Adafruit BMP585 (温度・気圧)
  - 接続先: M5Stack標準 Groveポート Port A (SDA=21, SCL=22)
- USB接続のバッテリパック 

## 開発環境
- PlatformIO + Arduino Workflow
- [Open Font Render](https://github.com/takkaO/OpenFontRender)
使用するライブラリは適宜追加する

## アプリケーション仕様
### 1. 表示する内容
- 温度
- 気圧

### 2. 表示先とデザイン
- **表示先**: M5Stackのディスプレイ
- **フォント**: NotoSansJP-Regular.ttf (`binaryttf.h` としてバイナリ化してプログラム領域に配置)
- **配色**: 
  - 数値部: シアン (Cyan)
  - テキスト部（「温度:」「℃」など）: 白 (White)

### 3. 表示形態
```text
温度: ##.# ℃
気圧：#### hPa
```
- 凡例#: ' ', 0..9
- 更新頻度: 1秒毎

### 4. エラー処理
- 初期状態: 各数値部に `Err` を表示
- 正常取得後: 取得エラーが発生した場合は前回値を保持して表示
- 連続エラー: 5回連続で通信・取得エラーが発生した場合は `Err` 表示に戻る

### 5. 起動画面
- 電源投入後、「Starting...」等の起動画面を表示
- センサーとの通信確立および初期化完了後、メイン画面へ遷移する

### 6. 省電力機能
- 起動、またはボタン操作から5分（300秒）経過で画面バックライトを消灯（暗くする）
- M5Stackの中央ボタン（BtnB）等の押下でバックライト点灯・画面復帰する

### 7. ホールド機能
- **ホールド操作**: M5Stackの `BtnA`（左側ボタン）を押下することで、その時点の測定数値（温度・気圧）を保持して画面上に固定します。再度押下すると解除し、リアルタイム計測値の表示に戻ります。
- **スリープ時の動作**: スリープ中（バックライト消灯中）の1回目のボタン押下は画面復帰のみを行い、ホールドの切り替えは行いません。
- **状態表示**:
  - 画面上部（Y=5）に `[計測中]`（緑色文字）または `[ホールド中]`（赤色文字）を常時表示します。
  - `BtnA` の上部（Y=200）に、計測中は `ホールド`、ホールド中は `解除` と白文字でガイドを表示します。
- **ホールド中のエラー処理**: ホールド中にセンサーの通信エラーが発生しても画面表示には反映（`Err` への切り替えなど）せず、ホールドされた数値を表示し続けます。ホールドを解除した時点でエラー判定が再開されます。
