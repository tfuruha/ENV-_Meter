# 減圧装置用 圧力モニター 仕様概要

## 1. プロダクトの使用目的
本プロダクトは、**自由研究などで使用する減圧装置の圧力（および温度）を監視・表示するモニター**です。  
減圧実験を行う際に、容器内の圧力状態をリアルタイムで安全かつ正確に確認できるようにすることを目的としています。

## 2. 使用するハードウェア
- [M5Stack basic 2.6](https://docs.m5stack.com/ja/core/BASIC%20v2.6)
- Adafruit BMP585 (温度・気圧センサー)
  - 接続先: M5Stack標準 Groveポート Port A (SDA=21, SCL=22)
- USB接続のバッテリパック 

## 3. 開発環境
- PlatformIO + Arduino Workflow
- 使用ライブラリ (`platformio.ini` の `lib_deps`):
  - `m5stack/M5Unified`
  - `Adafruit_BMP5xx` (GitHubリポジトリより)
  - [Open Font Render](https://github.com/takkaO/OpenFontRender) (GitHubリポジトリより)

## 4. アプリケーション仕様

### 1. 表示する内容
- 温度
- 気圧

### 2. 表示先とデザイン
- **表示先**: M5Stackのディスプレイ
- **フォント**: NotoSansJP-Regular.ttf のサブセット（`binaryttf.h` としてバイナリ化してプログラム領域に配置）
  - フォントサイズ: 36pt（数値・ラベル）、24pt（ステータス・ボタンラベル）
  - 使用文字セット: ` !"#$%&'()*+,-./0123456789:;<=>?@ABCDEFGHIJKLMNOPQRSTUVWXYZ[\]^_`abcdefghijklmnopqrstuvwxyz{|}~温度気圧℃計測中ホールド解除圧力低下警報スヌーズ`
- **配色**: 
  - 数値部（通常時）: シアン (Cyan)
  - テキスト部（「温度:」「℃」など）: 白 (White)
  - 数値部（警報時）: 赤 (Red)
  - 数値部（スヌーズ時）: 黄色 (Yellow)

### 3. 画面レイアウト
```text
[ステータス表示]          ← Y=5 (フォントサイズ 24pt)

温度: ##.# ℃             ← Y=55 (フォントサイズ 36pt)
気圧: #### hPa            ← Y=115 (フォントサイズ 36pt)

[ボタンラベル]            ← Y=200 (フォントサイズ 24pt)
```
- 凡例#: ' ', 0..9
- ラベル（「温度:」「気圧:」）: X=20
- 数値部: X=120
- 単位（「℃」「hPa」）: X=240

### 4. センサー設定 (BMP585)
- I2Cアドレス: 0x47（優先）、失敗時は 0x46 にフォールバック
- 温度オーバーサンプリング: 4倍
- 気圧オーバーサンプリング: 128倍
- IIRフィルター係数: 3
- 出力データレート (ODR): 10 Hz
- パワーモード: NORMAL（連続測定）
- 割り込み: データレディ割り込みを有効化（プッシュプル出力）

### 5. 測定・更新サイクル
- **ポーリング周期**: 25ms ごとに BMP585 のデータレディを確認し、新しいデータがあれば取得（ODR 10Hz に同期）
- **画面更新頻度**: 1秒毎（新しい測定データが到達した場合のみ更新）

### 6. エラー処理
- 初期状態: 各数値部に `Err` を表示（エラーカウントを最大値 5 で初期化）
- 正常取得後: 取得エラーが発生した場合は前回値を保持して表示
- 連続エラー: 5回連続で通信・取得エラーが発生した場合は `Err` 表示に戻る

### 7. 起動画面
- 電源投入後、「Starting...」等の起動画面を表示
- センサーとの通信確立および初期化完了後、メイン画面へ遷移する

### 8. 省電力機能
- **自動パワーオフ条件**: ボタン操作および大気圧復帰から5分（300秒）経過し、かつ **USB未接続（バッテリー駆動中）** の場合にデバイスを完全にパワーオフ（電源切断）します。
- **自動パワーオフの抑制（保護動作）**:
  - **減圧測定中**: リアルタイム測定気圧が 980.0 hPa 未満（減圧中）の場合は使用中とみなしてパワーオフを自動抑制します。
  - **USB給電中（充電中 / 満充電）**: IP5306電源管理IC（I2Cアドレス: `0x75`）のレジスタ `0x70` bit3（充電中）または `0x71` bit3（満充電）を検知した場合、給電中とみなしてパワーオフを自動抑制します。
- **再起動方法**: パワーオフからの再起動には、M5Stack側面の物理電源ボタン（赤）を押す必要があります。

### 9. ホールド機能（イベント時の圧力記録）
- **目的**: 実験中に現象が発生した瞬間（イベント発生時）の圧力をその場ですぐ記録・確認できるようにします。
- **ホールド操作**: M5Stackの `BtnA`（左側ボタン）を押すことで、その時点の測定数値（温度・気圧）を画面上に固定（保持）します。再度押すと解除され、リアルタイムの計測表示に戻ります。
- **状態表示**:
  - 画面上部（Y=5）に `[計測中]`（緑色文字）または `[ホールド中]`（赤色文字）を常時表示します。
  - `BtnA` の上部（Y=200）に、計測中は `ホールド`、ホールド中は `解除` と白文字でガイドを表示します。
- **ホールド中のエラー処理**: ホールド中にセンサーの通信エラーが発生しても画面表示には反映（`Err` への切り替えなど）せず、ホールドされた数値を表示し続けます。ホールドを解除した時点でエラー判定が再開されます。

### 10. 圧力過剰低下警報機能（容器破損リスク通知）
- **目的**: 圧力が過剰に低下すると、減圧容器が外気圧との差に耐え切れず**破損（潰れ・破裂など）するリスクが急増**します。そのため、危険な圧力レベルに達した際にユーザーへ即座に通知し、安全を確保します。
- **発報条件**: リアルタイム測定気圧が 700.0 hPa 以下になった場合に警報が発報します。
- **復帰条件**: リアルタイム測定気圧が 710.0 hPa 以上に回復すると警報およびスヌーズ状態が自動的に解除されます。
- **警報動作**:
  - 音声通知: 2000 Hz の間欠ビープ音（100ms ON / 500ms 周期）を鳴らして通知します。
  - 画面表示: ステータスが `[圧力低下警報]`（赤色文字）に変更され、気圧数値の表示色も赤色に変わります。
- **消音・スヌーズ操作**:
  - 警報が鳴っている間にいずれかのボタン（`BtnA`, `BtnB`, `BtnC`）を押すと、1分間スヌーズ（一時消音）に入ります。
  - スヌーズ中表示: ステータスが `[警報スヌーズ]`（黄色文字）に変更され、気圧数値の表示色も黄色に変わります。
  - 警報鳴動中のボタン押下時はホールド切り替え等の通常機能は作動せず、消音（スヌーズ）のみが最優先で実行されます。
